# 侠影文件夹总说明

根目录：手机存储 / xiaying/（文件管理器直接进）。
没开“所有文件访问权限”时，App 会用私有目录下的 xiaying/，功能照常用，只是在文件管理器里看不到。

| 文件夹 | 放什么 | 在 App 里哪里管 |
|---|---|---|
| js/ | drpy JS 规则，.js 文件 | 站源页 JS 相关入口，点文件名即激活 |
| py/ | 影视 PY 规则，.py 文件（hipy 风格） | 站源页 PY 相关入口，点文件名即激活 |
| py/book/ | 小说 PY 书源，.py 文件，须含 bookSearch | 书源页导入本地 PY |
| php/ | PHP 规则，.php 文件，走 CLI 引擎 | 站源页 PHP 相关入口 |
| php/t4_demo/ | T4 PHP 站点源，站点 .php 放根目录 | 订阅里 type=4 的站，见本目录说明 |
| php/t4_demo/lib/ | DZ 源另需的 spider.php 与 HtmlParser.php 各一份 | 同上，根目录那份不动 |
| web/ | 网页源配置，.json 文件 | 站源页网页源入口 |
| jar/ | 订阅 spider 的 jar 缓存，App 自动下载 | 不用手动放，删了下次用会重新下 |
| live/ | 直播插件，.json 文件 | 直播页，插件市场装直播插件即落这里 |
| plugins/ | 服务类插件，各插件一个子目录 | 插件市场装 server 插件即落这里 |
| service/ | 服务插件的工作目录，各服务一个子目录 | 服务页管理 |
| backup/ | 备份导出，.json 文件，文件名带时间戳 | 设置页备份与恢复 |
| log/ | 运行日志导出，.txt 文件 | 设置页调试里导出日志 |
| crash/ | 崩溃日志，只留最近 20 个 | 设置页调试里导出分享 |
| Download/ | 离线下载，每个任务一个子目录 | 下载管理页 |
| Screenshots/ | 播放器截图 | 播放器顶部栏截图按钮 |

已有文件不会被一键配置覆盖；卸载本插件不删这些目录和说明，更不删你放的规则文件。
